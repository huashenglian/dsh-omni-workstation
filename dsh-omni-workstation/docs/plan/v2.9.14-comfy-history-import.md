## 何时读取
排查 ComfyUI 自定义节点工作流（三方采样器/编码器/加载器）无法导入或无法注入、`detectComfyMapping` 报错、映射节点号/字段名覆盖、`/omni/comfy/history` 路由、历史导入弹窗、"从历史导入"按钮行为问题时先读本节。备份计划：`.trae/documents/v2.9.11-comfy-history-import-plan.md`（版本号顺延为 v2.9.14）。

## 背景 / 目标
用户在 ComfyUI 浏览器里调试好的工作流（常含大量三方自定义节点，如 Efficiency 采样器、自定义 TextEncode、自定义 Latent 创建器）粘贴/导入到插件后无法使用：本地 `comfyUiToApi` 转换会**静默丢弃 `object_info` 里不存在的节点**（损坏图），`detectComfyMapping` 又会因缺标准节点 **throw**（导入直接 400）。

方案采用**路径一（历史回放，零安装）**：不发送工作流，而是向服务器"要"工作流——用户在浏览器按过 Queue，服务端 `/history` 就存了**前端已转好的 API 格式图**（`prompt` 数组内）。取出后最小注入（正向 prompt/seed 随机化/尺寸/模型/步数等）原样 `POST /prompt` 重发。这张图由用户前端序列化、且在同一台服务器执行过（class_type 必然存在），插件从头到尾不认识任何三方节点，只认识注入点。

配套：映射检测全面降级（永不 throw，缺失→`missing[]`，泛化识别），映射配置项可增/删 + 字段名覆盖，教程浮窗。

## 设计要点

### 1. `detectComfyMapping` 永不 throw（index.js）
- 返回 `{ sampler, checkpoint, unet, vae, clip, latent, positive, negative, missing: [] }`；`missing` 随 mapping 一起存配置（注入只读固定键，未知键无害；UI 用它展示"未识别"）。
- 检测链（每条从标准 class_type 到泛化兜底）：
  - sampler：`KSampler`/`KSamplerAdvanced` → 首个 `inputs.positive`+`inputs.negative` 均为数组链接的节点（覆盖 Efficiency 等自定义采样器）。
  - latent：`EmptyLatentImage`/`EmptySD3LatentImage` → 首个 `inputs.width`/`inputs.height` 均为 number 的节点。
  - positive/negative：有 sampler 沿其链接（现逻辑）；无 sampler → 扫描 `class_type` 含 `TextEncode` 的节点（按节点 id 数字升序，第 1→positive、第 2→negative）。
- `missing` 原标签保留：`'采样器(KSampler)'`、`'模型加载器(Checkpoint 或 UNETLoader)'`、`'空Latent(EmptyLatentImage)'`。

### 2. 历史导入路由 `POST /omni/comfy/history`（index.js）
- `{action:'list', maxItems?}`（默认 30，钳 1–200）→ 代理 `GET {endpoint}/history?max_items=N`，逐条 `comfyHistoryPromptApi` 提取 API 图 → `{items:[{promptId, queue, status, nodeCount, hint}]}`，按队列号降序（最新在前）。
- `{action:'get', promptId}` → `GET {endpoint}/history/<id>` → `{ok, name, workflow(API图JSON字符串), mapping, basic:{steps,cfg,scheduler,seed}, missing, queue}`；name = hint 截 24 字符，空则 `历史 #<queue>`。
- `base = imggenConfig.endpoint`（空→400"请先填写 ComfyUI 端点 URL"）；headers 与生图一致（Bearer，若 apiKey）；`httpJson` 超时 30000。
- 纯函数（已导出供测试）：`comfyHistoryPromptApi(entry)`（防御式扫描 `prompt` 数组首个"值含 class_type 对象"的元素，**不硬编码下标 2**）、`comfyHistoryHint(api, mapping)`（正向 text 截 40 字符，无则模型名）、`comfyMapTarget(v)`（`'6'`→`{node:'6',field:''}`；`{node,field}`→归一；空→null）。

### 3. 注入块升级（index.js generate_image comfy 分支）
- 每角色经 `comfyMapTarget` 解析目标节点/字段：默认字段 checkpoint→`ckpt_name`、unet→`unet_name`、vae→`vae_name`、clip→`clip_name`、positive/negative→`text`。
- **字段守卫**：无字段覆盖时仅当节点 `inputs` 已含默认字段键才写（未命中→跳过，保留原值）；用户显式覆盖字段名则强制写（错了由 ComfyUI 校验错误如实暴露）。
- **latent 守卫**：width/height/`batch_size` 仅在节点已有对应键时写（自定义 Latent 缺 batch_size 不再 400）。
- **sampler seed 自适应**：`'seed' in inputs ? 'seed' : 'noise_seed' in inputs ? 'noise_seed' : 'seed'`（KSamplerAdvanced 场景）。
- 空映射兜底保持：`awf.mapping` 为对象（含全空）即按对象用，不落默认 5 键映射（历史导入的 mapping 恒为对象）。

### 4. `applyPatch` 映射操作（index.js）
- `comfyWfUpdateMapping.value` 支持 `string | {node, field}`；**空节点对象保留空行**（用户可继续填；与 UI"添加映射"配合），string 空串存 `''`，仅 `null/undefined` 删除。
- 新增 `comfyWfDeleteMapping {id, key}` → `delete wf.mapping[key]`（删除行主路径）。

### 5. prepared 导入通道（index.js `/omni/config` POST 预解析）
- `patch.comfyWfImport.prepared === true` 跳过 `prepareComfyWorkflow`，仅校验 `JSON.parse` 合法 + mapping 必须对象；id 由 applyPatch 兜底生成。历史导入走单一写路径（applyPatch→storeConfig→syncToolRegistration）。

### 6. 客户端（client.js）
- **WorkflowList**：标题行加 "?" 帮助按钮；按钮行 `.omni-comfy-wf-actions` = 文件导入 + **「从历史导入」**。
- **WorkflowHistoryModal**：队列号/状态徽标（成功绿/失败红/未知灰）/节点数/prompt 摘要 +「导入」按钮（busy 态）+ 刷新 + 关闭；空态/错误态文案。**WorkflowHelpModal**：覆盖层静态教程（推荐历史路径两步 + 手动 Save (API Format) + 映射说明），不占面板空间。
- **WorkflowEdit 映射区重构**：8 角色逐行（标签 + 节点框 + 可选字段框[仅单字段角色] + ✕ 删除）；"添加映射"按钮（仅列尚未入 mapping 的角色，点击追加空行 `{node:"",field:""}`）；摘要行（`Label: node.field`）+ 未识别警示行（`mapping.missing`）。
- App handlers：`fetchComfyHistory`（call `comfy/history` list）、`importComfyHistory`（call get → `commitStructure({comfyWfImport:{...prepared:true}})`，missing 时 warning toast）。
- 弹窗进出 ~120ms fade+pop（CSS keyframes，mount/unmount 可中断）；背景 token 复用 `--dsw-alias-bg-layer-2`（对齐 `.VOzbGW_panel` 父容器）。

## 已知坑
- ComfyUI `/history` 条目：`prompt: [queueNo, promptId, apiPrompt, extraData, outputsToExecute]`，API 图在**下标 2**，但实现不硬编码（防御式扫描）——结构多年稳定，但兼容趴着来最稳。
- `comfyUiToApi` 会静默丢 `object_info` 不存在的节点——历史路径绕开它（UI 格式导入仍走它，勿改）。
- KSamplerAdvanced 的 seed 字段是 `noise_seed`——注入写死 `seed` 会无效；已自适应。
- 自定义 Latent 节点常无 `batch_size`——无条件写会 400；已守卫。
