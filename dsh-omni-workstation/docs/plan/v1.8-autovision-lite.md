# v1.8 — Auto Vision Lite (2026-08)

> [Back to root AGENTS.md](..) · [v1.7 ↗](./v1.7.md) · [Changelog ↗](../changelog/changelog.md)

## 核心变更

VLM ON → picker 只多 **1 条** "+ Auto Vision"（不再是 v1.7 每 provider 镜像整组模型）。

| 变更点 | v1.7 | v1.8 |
|---|---|---|
| twin 路由 | `<provider>-omni-workstation` per source | 固定 `auto-vision`（1 条） |
| listModels | 镜像整组源模型 | 返回 1 项 `[id:'auto-vision', name:'Auto Vision', inputModalities:['text','image']]` |
| resolveModel | 映射到源模型的 resolved info | 永远 `{id:'auto-vision', ...}` |
| stream 委派 | `ctx.llm.stream({...options, provider, messages: rewritten})` | `stream({..., provider: lastSourceProvider, model: lastSourceModel, ...})` |
| state | 无追踪 | `lastSourceProvider`/`lastSourceModel` 模块级 let，由 `agent/request` event 更新 |

## agent/request waterfal hook

`ctx.on('agent/request')` handler 必须 `await next()` 且 **RETURN config**（waterfall return = outermost listener's return；undefined 会毁掉 agent）。twin reconcile fire-and-forget 不阻塞请求。过滤 `auto-vision/-omni-workstation/-vision` 防止 self-recursion。
