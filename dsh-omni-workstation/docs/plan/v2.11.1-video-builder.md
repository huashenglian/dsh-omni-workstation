# v2.11.1 — 视频卡片上限 + /build-video-tool 自定义视频工具构建

何时读取：改视频卡片上限、斜杠指令构建器、custom-adapter 协议时。

## 需求摘要

1. 视频卡片上限可配置（默认 10，硬顶 10）
2. 设置 → 开关扩展 → 视频折叠区：斜杠指令开关 + 上限输入
3. `/build-video-tool` 触发时程序检测上限；未达则 steer 注入构建指南
4. AI 卡片带 AI 徽章、无预设行、可折叠/删除/编辑
5. 脚手架 + 详细指南；上限物理门禁
6. E2E：发送 happyhorse 构建 prompt 验证全链路

## 数据模型

- 配置：`videoCardLimit` (1–10, default 10)、`videoBuilderEnabled` (default true)
- 卡片：`source: 'user'|'ai'`；config.protocol 可为 `custom-adapter` + `adapterCode`

## 指令行为

```
用户 /build-video-tool [可选 prompt]
  → handler: cards.length >= limit ? error : steer(guide)
  → AI 按指南 POST /omni/config { videoCardAddAi: {...} }
  → 卡片 source=ai，前端 AI 徽章，工具注册
```
