# v2.8 — 视频生成面板 + generate_video 工具 (2026-08)

> [Back to root AGENTS.md](..) · [Changelog ↗](../changelog/changelog.md)

## 目标

全模态扩展第三步：设置页新增「视频」tab（替换占位），host 半新增 `generate_video` 工具（t2v + i2v）。视频生成是**异步任务协议**（提交 → 轮询 → 取片），与生图同步协议本质不同。核心门控：`videoEnabled !== true` 或配置无效时工具完全不注册（tool schema 不注入 → 0 token）。

## 协议与供应商

| 协议 | 提交 | 轮询 | 取片 |
|---|---|---|---|
| `openai-videos` | `POST {base}/videos` | `GET {base}/videos/{id}` | 响应含 url 直接下载；Agnes 完成仅回 `video_id`，再 `GET /agnesapi?video_id=` 拿 cos mp4 地址（实测）；Sora 中转站回退 `{pollPath}/{id}/content` |
| `dashscope-video` | `POST /api/v1/services/aigc/video-generation/generation`（X-DashScope-Async）+ workspace host 重写标准域名 | `/api/v1/tasks/{id}` | `output.video_url` |
| `kling-video` | `POST /v1/videos/text2video|image2video`（JWT HS256） | `/v1/videos/{kind}/{id}` | `data.task_result.videos[0].url` |
| `volc-video` | `POST /api/v3/contents/generations/tasks`（content 数组，图片 data URL first_frame） | `/api/v3/.../tasks/{id}` | `content.video_url.url` |
| `minimax-video` | `POST /v1/video_generation` | `/v1/query/video_generation?task_id=` | 成功后二次 `/v1/files/retrieve` 拿 `file.download_url` |
| `async-task` | `POST {base}{submitPath}` | `{pollPath}`（支持 `{id}` 占位） | `resultField` 点路径 |

供应商：`custom`（默认，可自选协议）、`agnes`/`agnes-cn`（fixed openai-videos）、`qwen-token-plan`/`qwen-token-plan-cn`（fixed openai-videos，Token Plan OpenAI 兼容网关 `token-plan.*.maas.aliyuncs.com/compatible-mode/v1`）、`dashscope`（endpoint 可编辑，支持 workspace 专属域名）、`kling`（key 格式 `AccessKey|SecretKey`）、`volc`、`minimax`。Sora/OpenAI 移除（渠道全关，无 key 可验）。

## 门控与配置

- `videoEnabled` 默认 **false**；`videoVisible = videoEnabled === true && isVideoConfigValid(videoConfig)`（provider+endpoint+model+apiKey 非空；kling 需含 `|`）
- `videoConfig`：`timeoutMs:600000`、`pollIntervalMs:5000`、`retryCount:1`、`seconds:5`、`aspectRatio:'16:9'`、`resolution:'720p'`、async-task 专属 `submitPath/pollPath/taskIdField/statusField/resultField/doneStatus`
- 路由：`/omni/config`（GET/POST 回 `videoVisible`）、`/omni/models {video:true}`（video/t2v/i2v/wan/kling 过滤）、`/omni/key {video:true}`
- 文件落盘：`{sessionCwd}/{output_dir||.}/video_<ts>.mp4`（复用 sessionCwd 回退链，不回退 process.cwd()）

## 实测修正（重要）

Agnes V2.0 轮询完成后响应**不含结果 URL**，仅 `video_id`；`GET /v1/videos/{id}/content` 返回 `{"detail":"Not Found"}`（误导）。正确路径：`GET /agnesapi?video_id=<video_id>` → 响应 `url` 字段为 cos 平台 mp4 下载地址。执行器对 agnes/agnes-cn 完成时走该路径，custom 回退 content 端点。
