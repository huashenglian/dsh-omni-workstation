## 背景 / 目标
v2.9.7 适配音色库（10 个预置音色下拉），但豆包合成和复刻功能未实现。用户要求：前端上传音频 → 复刻 → 记忆音色 → AI 可用复刻音色合成 + AI 可自行复刻并后续复用。

## 设计要点

### TTS 合成（runDoubaoTts）
- `POST https://openspeech.bytedance.com/api/v3/tts/unidirectional`
- Auth: `X-Api-App-Key`(appId) + `X-Api-Access-Key`(accessKey) 或 `X-Api-Key`(apiKey 新版)
- `X-Api-Resource-Id` = model（`seed-tts-2.0` / `seed-icl-2.0` / `seed-icl-1.0`）
- Body: `{user:{uid}, req_params:{text, speaker, audio_params:{format:'mp3', sample_rate:24000}, additions}}`
- 响应：chunked JSON 流（逐行 JSON.parse → base64 拼接 → atob → mp3 buffer）
- 不支持内联参考音频（TTS API 只接受 speaker_id）

### 声音复刻（doDoubaoClone）
- `POST /api/v3/tts/voice_clone` — base64 音频入 JSON body（非 multipart）
- 后付费：`speaker_id='custom_speaker_id'`，`custom_speaker_id` = 用户定义（8-256 字符，字母开头）
- 训练异步：轮询 `POST /api/v3/tts/get_voice` → status 0=NotFound/1=Training/2=Success/3=Failed/4=Active
- 同步等待最多 120s（3s 间隔），超时返回 status=1（AI 可重试）
- 无需预购槽位（后付费模式）

### 鉴权设计
- 双模式：legacy（appId+accessKey 头）或新版（apiKey as X-Api-Key）
- `isVoiceConfigValid` doubao：接受 appId+accessKey 或 apiKey（二选一）
- `runDoubaoTts`/`doDoubaoClone`：`if (appId) headers['X-Api-App-Key']=appId; if (accessKey) headers['X-Api-Access-Key']=accessKey; else if (apiKey) headers['X-Api-Key']=apiKey`

### 面板 UI（DoubaoCloneSection）
- 文件选择（audio/*）→ FileReader.readAsDataURL → base64
- speaker_id 输入框（auto-fill filename，需 8-256 字符字母开头）
- 克隆按钮 → POST /omni/doubao/clone → 成功 patchVoice('voiceId', speaker_id)
- 仅 provider==='doubao' 时渲染

### 工具集成
- `speak` execute：`vc.provider === 'doubao' ? runDoubaoTts(vc, args, exec)`
- `clone_voice` execute：doubao 分支调 `doDoubaoClone` → 返回 speaker_id
- `syncToolRegistration`：speak + clone_voice 均注册 mimo+minimax+doubao
