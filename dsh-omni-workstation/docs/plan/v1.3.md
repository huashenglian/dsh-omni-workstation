# v1.3 — 多模态卡片重构 (2026-08)

> [Back to root AGENTS.md](..) · [v1.4 ↗](./v1.4.md) · [Changelog ↗](../changelog/changelog.md)

配置模型由 `api:{primary,backup}` 改为 **`apis: Card[]`**。

- **cards: Card[]** 数组即优先级（从上到下）。每次请求从顶部重新开始，无持久活动态。字段：`id/name/provider/protocol/endpoint/apiKey/model/collapsed/timeoutMs`。协议：`openai-completions`、`openai-responses`、`anthropic-messages`、`google-gemini`；供应商：`custom`（需 key）、`ollama`（仅 URL）。
- **回退 = 单次请求内**：单卡重试超 `retryCount` 或遇不可重试错误即回退下一卡；**超时立即回退下一卡不重试**。
- 后续 v1.4 追加了卡片级 timeout、JPG→PNG 重编码兜底、动态工具注册等。
