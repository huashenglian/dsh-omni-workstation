# v2.9.13 — 豆包语音双区独立 V1/V3 鉴权 + 自定义音色自动 ICL

> [Back to AGENTS.md](../../../AGENTS.md) · [Changelog ↗](../changelog/changelog.md)

## 何时读取
排查 doubao 上/下两区（生成 vs 复刻）各自 V1/V3 协议切换、Key/App ID/Token 独立配置、自定义音色自动切 ICL 模型与凭据、V1 TTS 鉴权头（X-Api-App-Id）问题时先读本节。

## 背景 / 目标
用户要求豆包语音面板**上（生成语音）/下（复刻自定义音色）两个独立配置区**都能自主切换 API 协议（V1 旧版控制台 / V3 新版控制台）并持有各自凭据：V1 = App ID + Access Token，V3 = KEY。两区可配不同 KEY / App ID+Token。选"（自定义）"复刻音色时自动用复刻区 ICL 模型合成（内置 `*_bigtts`/`ICL_uranus_*` 音色与复刻 `S_` 音色不能混用模型）。

## 设计要点

### V1 TTS 合成鉴权修正（runDoubaoTts）
- **V1（旧版控制台）合成按官方文档**：`X-Api-App-Id` + `X-Api-Access-Key` + `X-Api-Resource-Id` + `X-Api-Request-Id`（合成**不用** `Authorization: Bearer`——那是 mega_tts 克隆接口的鉴权）。端点不变：`/api/v3/tts/unidirectional`。
- **V3（新版控制台）**：`X-Api-Key` 优先；无 KEY 时回退 `X-Api-App-Key`+`X-Api-Access-Key`（兼容旧配置）。
- `runDoubaoTts` V1 分支缺 App ID/Access Token 直接抛错（防静默发错鉴权头）。

### 双区独立配置（UI）
- 上方生成区：doubao 显示"API 协议"选择器；V1 → App ID + Access Token 行，V3 → KEY 行（v2.9.12 只有协议选择器+V1 隐藏 KEY，无 V1 凭据输入框）。
- 下方复刻区（`DoubaoCloneSection`）：每个预设自带协议选择器 + 按协议切换凭据行（V1 = App ID+Token / V3 = KEY），预设新增 `apiKey` 字段；两区互不串值。
- `isVoiceConfigValid` doubao：V1 要求上方自带 appId+accessKey，V3 要求 apiKey（工具门与协议一致）。

### 自定义音色自动 ICL（speak）
- 新增纯函数 `resolveDoubaoClonePreset(speaker, cfg)`（导出）：speaker 精确命中预设 `speakerId` → 用该预设；未命中但 `S_` 前缀 → 活动预设兜底（覆盖 AI 克隆后未经面板记录直接合成的场景）；其余（内置音色）→ null。
- `speak` doubao 分支命中预设时：**预设为唯一凭据源**（model=cloneModel、apiVersion=预设协议、appId/accessKey/apiKey 只取预设值，不复用上方 vc——防止 V3 预设泄漏上方遗留 V1 凭据）。
- `clone_voice` doubao 分支与 `/omni/doubao/clone` 路由同步改为预设唯一凭据源 + 预设协议优先（apiVersion = `dcp.apiVersion || vc.apiVersion`）。

## 涉及路径
- `lib/index.js`：`runDoubaoTts` V1/V3 鉴权头、`resolveDoubaoClonePreset`（+export）、`speak` doubao 分支、`isVoiceConfigValid` doubao v1 校验、预设 schema/applyPatch 加 `apiKey`（normalize/默认/add/patch）、`clone_voice` 与 `/omni/doubao/clone` 凭据源与协议优先级、`buildSpeakToolDef` doubao 描述（提示自动 ICL）。
- `lib/client.js`：上方区 V1 App ID+Access Token 行 / V3 KEY 行；`DoubaoCloneSection` 加协议选择器 + V3 KEY 输入行 + 预设新增 `apiKey`。
- `tests/voice.test.js`：isVoiceConfigValid doubao v1/v3 真实函数用例、resolveDoubaoClonePreset 4 例、runDoubaoTts V1/V3 请求头断言、applyPatch apiKey 持久化。
