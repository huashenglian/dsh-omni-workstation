### v1.4（追加）
- `timeoutMs` 默认 120000，`clampTimeout` 钳到 [1000, 3600000]
- **JPG→PNG 重编码兜底**：仅 `isJpeg && (400|415)` 时惰性触发一次，vendor jpeg-js → `lib/vendor/png.js`（node:zlib 手写编码）→ 同卡立即 PNG 重试一次
- **安装副本 `.pnpm` 为空，无依赖可解析 → 必须 vendor 纯 JS**；`.cjs` 后缀规避包根 `"type":"module"`
- UI：模型计数在列表标题右侧、眼睛开关固定 SVG 按钮、模型下拉自定义组件非原生 select、拖拽手柄常驻

### v1.6 — 生图模块 imggen
- 新工具 `generate_image`：`prompt`(必填)/`size`/`n` 参数 → `{cwd}/generated-images/img_<ts>_<i>.png`
- **imggenConfig 单对象配置**（非数组）：protocol 支持 `openai-images`（族 A）和 `openai-completions`（族 B）。`responseFormat:'auto'` 时省略 `response_format` 字段。
- 可选参数**必须省略 `required` 键**（dsh-tools schema 编译器拒绝 `required:false`，启动即崩）
- 真实集成经验：agnes-image-2.1-flash API 拒绝任何 `response_format` 显式值（400），只能省略让服务端返回 URL
