# v2.9.7 — 统一 clone_voice + 语音面板修复

> [Back to AGENTS.md](../../../AGENTS.md) · [Changelog ↗](../changelog/changelog.md)

## 何时读取
排查 voice 工具不注册、clone_voice 与 speak 的复用关系、key 眼睛按钮不显示、provider 切换后 voiceId 错误（如 mimo_default 残留到 doubao）、豆包音色下拉不显示时先读本节。

## 背景 / 目标
v2.9.3 的 `minimax_clone_voice` 是 clone+synthesize 一步到位（一次性），voice_id 不持久化，AI 无法在后续 speak 中复用。旧的 mimo `clone_voice` 也是 clone+synthesize 一步。用户要求：
1. AI 克隆后能后续复用（不只一次性）
2. AI 能使用用户在面板配置的音色
3. 不冲突（AI 克隆不覆盖用户配置）
4. 正常情况 AI 只用配置的音色，仅在用户明确要求时才克隆
5. 掩盖旧克隆工具

同时修复两个面板 bug：key 眼睛按钮不显示、provider 切换 voiceId 不重置。

## 设计要点

### 统一 clone_voice（clone-only）
- 新 `buildCloneVoiceToolDef`：clone-only（不合成），mimo+minimax 均注册
- minimax：调 `doMinimaxClone` → 返回持久 voice_id → AI 后续 speak 传 `voice=<voice_id>`
- mimo：验证采样文件存在 → 返回 voice_sample_path → AI 后续 speak 传 `voice_sample_path=<path>`
- `demo_audio` 条件性返回（text 未传时不包含——output schema `type:'string'` 不能返回 null）
- voice_id 防冲突 guard：拒绝 `voice_id === vc.voiceId`
- 共享 `existsSync` 校验（minimax 和 mimo 分支前都检查文件存在）

### speak 工具更新
- 加 `voice_sample_path` 参数（**mimo-only**，minimax 不广告——防误导）
- execute 覆写：`if (args.voice_sample_path && vc.provider === 'mimo')` → model 覆写为 `mimo-v2.5-tts-voiceclone` → `runMimoTts`（line 2721 已处理 base64 inline）
- guard 用 `=== 'mimo'`（非 `!== 'minimax'`）——execute 读 live config，provider 可能切换到 doubao 等
- description provider-aware：minimax 提示 voice_id 复用，mimo 提示 voice_sample_path 复用

### 防冲突设计
- AI 克隆结果仅存对话上下文（tool result），不写 omni-vision.json
- `speak` 的 `args.voice || vc.voiceId` / `args.voice_sample_path` 优先级链天然支持 AI 覆盖
- AI 不传参数 → 用配置的 voiceId（默认路径）
- AI 传 voice/voice_sample_path → 覆盖配置（克隆路径）

### /omni/key voice 分支
- `POST /omni/key {voice:true}` → 返回 `voiceConfig.apiKey`
- 读 `loadConfig` 原始 config（**不读** `maskedVoice`——后者只返回 `apiKeySet: boolean`）

### provider 切换 voiceId 重置
- `applyPatch` provider 变更时：mimo→`mimo_default`、doubao→`zh_female_vv_uranus_bigtts`、其余→空
- **minimax 除外**——保留克隆 voice_id（`runMinimaxTts` 空 voiceId 抛错）
- 客户端 `changeVoiceProvider` 同步更新本地 draft

### 豆包音色库
- `DOUBAO_PRESET_VOICES`（client.js 常量，10 个 seed-tts-2.0 音色，来自 `文档/豆包.txt`）
- 面板 `Field`→`SelectField` 下拉（含 stale-value 兜底）
- `fetchVoiceModels` doubao 分支填充 `voiceVoiceList`
- 默认 Vivi 2.0（`zh_female_vv_uranus_bigtts`）
- 复刻功能后续实现

## 涉及路径
- `dsh-omni-workstation/lib/index.js`：`buildCloneVoiceToolDef`（替换）、`buildMinimaxCloneVoiceToolDef`（删除）、`buildSpeakToolDef`（更新）、`syncToolRegistration`（更新）、`/omni/key`（加 voice 分支）、`applyPatch`（voiceId 重置）、export（加 `buildCloneVoiceToolDef`/`buildSpeakToolDef`）

- `dsh-omni-workstation/tests/voice.test.js`：新增 8 例（工具定义 + applyPatch voiceId 重置）
