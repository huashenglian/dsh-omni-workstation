# v2.10 — 本地语音供应商完善（IndexTTS / GPT-SoVITS / VoxCPM / TTS-WebUI 桥接）

## 背景

v2.9 语音模块已接入 mimo + minimax + doubao 三个云端供应商，但 VOICE_PROVIDERS 表中还有 4 个本地供应商（indextts/gptsovits/voxcpm/tts-webui）仅有元数据定义，无合成函数、无克隆函数、syncToolRegistration 不注册工具。用户切换到这些供应商时 voiceStatusNoSynth 显示"speak 工具已隐藏"。

## 目标

完善 4 个本地供应商的工具功能（复刻 + 生成），严格对照 Siren-Voice 参考项目的 API 模式实现。遵守动态工具注册与动态提示词注入规则，切换供应商或关闭语音模块时工具与提示词自动消失。

## 实现

### 1. voiceConfig 字段扩展

`defaultVoiceConfig` + `normalizeVoiceConfig` + `maskedVoice` 三处同步新增 6 字段：
- `gptModel`、`sovitsModel`、`refAudioPath`、`refText`、`promptLang`（默认 '中文'）、`textLang`（默认 '中文'）

字段映射（camelCase → snake_case payload）：
- gptModel → gpt_model_name
- sovitsModel → sovits_model_name
- refAudioPath → ref_audio_path
- refText → **prompt_text**（注意：是 rename，不是 casing 变换）
- promptLang → prompt_text_lang
- textLang → text_lang

### 2. 合成函数

| 函数 | 端点 | 认证 | 响应 |
|---|---|---|---|
| `runIndexTts(vc,args,exec)` | POST {endpoint}/api/v1/tts/tasks | Authorization: Bearer（apiKey 非空时） | blob → wav |
| `runGptSovits(vc,args,exec)` | POST {endpoint}/infer_classic | app_key 在 body（不在 header） | blob → wav |
| `runVoxCpm(vc,args,exec)` | POST {endpoint}/v1/audio/clone 或 /v1/audio/design | X-API-Key（不是 Bearer） | blob → wav |
| `runTtsWebui(vc,args,exec)` | POST {endpoint}/v1/audio/speech | Authorization: Bearer（apiKey 非空时） | blob → wav/mp3 |

### 3. 克隆函数

| 函数 | 端点 | 认证 | 返回 |
|---|---|---|---|
| `doIndexTtsClone(vc,refPath,exec)` | POST {endpoint}/api/v1/upload | Authorization: Bearer | {voice_id} |
| `doVoxCpmClone(vc,refPath,exec)` | POST {endpoint}/v1/audio/upload | X-API-Key | {voice_id} |
| GPT-SoVITS | 内联（验证 refAudioPath 存在即返回） | — | {voice_sample_path} |
| TTS-WebUI | 不注册 clone_voice | — | — |

### 4. 动态注册

`syncToolRegistration` voice block：
- speak 注册条件：全部 7 供应商（mimo+minimax+doubao+indextts+gptsovits+voxcpm+tts-webui）
- clone_voice 注册条件：6 供应商（不含 tts-webui）；VoxCPM 仅 mode='clone' 时注册
- voiceSig 已含 provider，切换即重注册

### 5. model 门控修复

`isVoiceConfigValid` 要求 `c.model` 非空。indextts/voxcpm API 无 model 概念 → `changeVoiceProvider` 为它们设 placeholder `model='default'`。gptsovits/tts-webui 需用户在面板填 model（同 mimo/minimax）。

### 6. 面板 UI

- 移除 voiceStatusNoSynth 阻断（所有 7 供应商已接入合成）
- gptsovits 新增 4 个配置字段（gptModel/sovitsModel/refAudioPath/refText）
- i18n 新增 4 个 key（中英文）
- changeVoiceProvider 新增 model 重置

### 7. 路由

- `POST /omni/indextts/clone` — 面板上传参考音频（base64 落 voice-library 后调 doIndexTtsClone）
- `POST /omni/voxcpm/clone` — 同上（调 doVoxCpmClone）
- gptsovits 语音拉取走现有 fallback（index.js 末尾 `return {ok:true, voices:[], note:'no fetch API for '+provider}`）
