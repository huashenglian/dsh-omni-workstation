# v2.9 — 语音模块（Voice）：speak / clone_voice + MiMo TTS (2026-08)

> [Back to AGENTS.md](../AGENTS.md) · [Changelog ↗](../changelog/changelog.md)

## 目标

全模态扩展第四步：设置页新增「语音」tab（含 TTS/STT 子 tab），host 半新增 `speak` 与 `clone_voice` 两个 TTS 工具。STT（`transcribe`）仅声明、**永不注册**——STT 尚未实现。核心门控：`voiceEnabled || ttsEnabled` 任一 false 或 `voiceConfig` 无效时，两个工具完全不注册（schema 不注入 → 0 token）。UI 沿用设置页四模块开关范式（VLM | 生图 | 视频 | **语音**），语音关时 tab 整体灰化（`omni-tab-disabled`）。

## 供应商与协议

| 供应商 key | 类型 | endpoint 模型 |
|---|---|---|
| `custom` | 自定义 | 用户填 endpoint/model/apiKey |
| `mimo` | **唯一可跑** | 固定 `https://mimo.cdn.mimosec.cn/openai/v1`，3 模型 `mimo-v2.5-tts` / `mimo-voicedesign` / `mimo-voiceclone` |
| `openai-tts` / `elevenlabs` / `azure-tts` / `google-tts` / `dashscope` / `gemini-tts` | **纯预设占位** | 下拉可选择，执行时 stub 报错 `Only MiMo provider is implemented` |

**MiMo 协议（实测）**：走 OpenAI chat completions 兼容接口。
- `POST /chat/completions`，`model=<miMoModel>`，`messages: [{ role:"assistant", content: text }]`
- 响应：`choices[0].audio` 字段 = 音频数据（base64 字符串或 Buffer），`wav` 格式
- 采样率固定 24000，无需单独传；`temperature` 传 1.0

**音色克隆**：零注册流程，`audio.voice` 字段直接传 base64 采样音频（MiMo 服务端即时克隆），无需预建 voice id。

## 门控与配置

- `voiceEnabled` 默认 **false**（第四模块开关）；`ttsEnabled` 默认 **true**（TTS/STT 子开关，STT 占位用）
- `voiceVisible = voiceEnabled === true && ttsEnabled === true && isVoiceConfigValid(voiceConfig)`
  - 校验：`tts.provider` + `tts.endpoint` + `tts.model` + `tts.apiKey` 均非空
- `voiceConfig` 结构：`{ tts: {provider, endpoint, model, apiKey, timeoutMs}, stt: {provider, endpoint, model, apiKey, timeoutMs} }`
  - `timeoutMs` 默认 60000，`clamp(5000, 600000)`
  - `maskedVoice`：返回给前端的配置自动对 apiKey 打码（`****` 前 4 位）
- 路由：`/omni/config`（GET 回 `voiceVisible`，POST 走 `applyPatch` 的 voice 分支）
- 文件落盘：`{sessionCwd}/{output_dir||.}/voice_<ts>.wav`（复用 sessionCwd 回退链）

## 工具详情

| 工具 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `speak` | `text`, `voice`(可选), `speed`(0.5–2.0, 默认 1.0) | `{ path, size }` | 普通 TTS，非 MiMo 供应商报 `Only MiMo provider is implemented` |

## 实测修正

- MiMo 响应里音频在 `choices[0].audio` 字段（不是 `audio_response.audio` 也不是单独 `/audio` endpoint）——`Buffer.from()` 直用 base64 字符串即可，无需二次 decode
- `clone_voice` 采样音频长度要求：≥ 1s，推荐 3–10s；过长被 MiMo 截断，过短克隆效果差
- STT 子 tab 保留但 STT 部分**纯占位**（`ttsEnabled` 默认 true，STT 默认关），避免误以为可录；STT 工具定义 `transcribe` 仅在 DICTS 里出现，注册函数永不调用
