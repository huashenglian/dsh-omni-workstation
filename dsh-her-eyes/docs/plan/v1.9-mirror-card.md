# v1.9 — Mirror Model Card (镜像模型) (2026-08)

> [Back to root AGENTS.md](..) · [v1.8 ↗](./v1.8-autovision-lite.md) · [Changelog ↗](../changelog/changelog.md)

## 目标

在 设置 → 多模态 → VLM 面板，兜底模型卡片下方，新增「镜像模型」卡片。卡片可收纳/展开，默认收纳。提供三个独立开关/列表控制 `/model` 中的镜像模型条目。

## 卡片结构

```
┌─ 镜像模型（默认收纳）────────────────────┐
│ ▼ 展开后：                                │
│   [开关1] auto-vision 自动路由            │
│   [开关2] 镜像全部模型（开启后掩盖下方列表）│
│   ── 模型映射列表（开关2 ON 时禁用）──    │
│   [选择框: 原模型▾] [输入框: 镜像名] [🗑] │
│   [选择框: 原模型▾] [输入框: 镜像名] [🗑] │
│   [+ 添加映射]                            │
└──────────────────────────────────────────┘
```

### 选择框（左侧）
- 点击后自动拉取全部已注册模型
- **按 provider 分组**，provider 名作为小字体类别标题：
  ```
  deepseek            ← 类别标题（小字）
    deepseek-v4-pro
    deepseek-v4-flash
  魔搭                 ← 类别标题
    GLM-5.2
    deepseek-v4-flash-0731
  ```
- 选中后内部捕获 `{provider, model}`，显示 model 名

### 输入框（右侧）
- 自定义镜像模型名，默认留空
- 留空 → `<originalModel>-vision`（连字符，与 `auto-vision` 一致）

## 三种模式（独立）

| 开关1 autoVision | 开关2 mirrorAll | 列表 | /model 结果 |
|---|---|---|---|
| OFF | OFF | 空 | 无镜像条目 |
| ON  | OFF | 空 | 1 条 `auto-vision` |
| OFF | ON  | 任意 | 每 provider 一组 `*-her-eyes`（列表被掩盖） |
| ON  | ON  | 任意 | `auto-vision` + 每 provider 一组（列表被掩盖） |
| OFF | OFF | N 条 | N 条自定义镜像 |
| ON  | OFF | N 条 | `auto-vision` + N 条自定义镜像 |

- 开关2 ON = 列表条目不注册 twin（per-provider twin 已覆盖全部模型）
- 列表 UI 在开关2 ON 时视觉禁用/灰显

## Config schema

```json
{
  "mirrorConfig": {
    "autoVisionEnabled": false,
    "mirrorAllEnabled": false,
    "mappings": [
      { "id": "m_xxx", "originalProvider": "...", "originalModel": "...", "mirrorName": "" }
    ]
  }
}
```

## 后端变更（index.js）

1. `normalizeConfig`：加 `mirrorConfig`（默认全 false + 空 mappings）
2. `masked()`：暴露 `mirrorConfig`
3. `applyPatch()`：处理 `mirrorConfig` patches（toggles / addMapping / removeMapping / updateMapping）
4. `syncTwins()` 扩展：
   - `autoVisionEnabled` → 注册 `auto-vision` 单例（复用现有 v1.8 makeTwinAdapter，改为 gated）
   - `mirrorAllEnabled` → 每 live non-twin provider 注册 `<provider>-her-eyes`（v1.7 per-provider 镜像）
   - `!mirrorAllEnabled && mappings.length > 0` → 每条 mapping 注册一个 twin（route = mirrorName，delegate 到 originalProvider/originalModel，image blocks → markers）
5. 新路由 `/vlm/all-models`：返回 `[{provider, model, providerName}]` 供前端下拉

## 前端变更（client.js）

1. i18n 字符串（zh + en）
2. `MirrorCard` 组件（收纳/展开，默认收纳）
3. 状态/hooks：`mirrorCollapsed`, `mirrorModels`, `patchMirror`, `addMapping`, `removeMapping`, `updateMapping`, `fetchAllModels`
4. 插入 `vlmBody`，在 `FallbackCard` 之后、`vlm-list` 之前
5. CSS：分组标题小字体、灰显状态

## 热更新

UI edit → queueSave/commitStructure → POST /vlm/config → applyPatch → storeConfig → syncToolRegistration() → syncTwins() dispose 旧的 + 注册新的。twin stream() 在调用时读 config，对话中途改映射下一轮生效。
